# Last Boat

A short run along the Western Brook Pond boardwalk. The tour boat has already sounded its horn. Jump the rocks, duck the spruce, and reach the dock before the sailing leaves.

Play it on FunApps at [/play/last-boat/](https://funapps.ca/play/last-boat/).

## Controls

- Space, or the right side of the screen, jumps.
- Down arrow, S, or the left side ducks.
- P pauses.

## Build

```bash
npm install
npm run build
```

The static release is written to `web/` and copied to `/play/last-boat/` by the hub build. Asset paths are relative so the game works in that subdirectory.
